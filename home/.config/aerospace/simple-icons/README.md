# Vendored Simple Icons

These SVGs are a small, pinned subset of [Simple Icons](https://simpleicons.org/),
downloaded from `simple-icons@16.27.0`. They are rendered locally and tinted to
the SketchyBar theme. `simple-icons.bundle-map` maps stable macOS bundle IDs to
these files; unlisted apps can use a hand-picked Victor Mono Nerd Font glyph,
then fall back to the local app-icon renderer. The current glyph overrides live
in `../victor-mono.bundle-map`.

Simple Icons is distributed under CC0, but its project asks users to review each
brand's guidelines and license data. See its [disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md).
